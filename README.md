# 🔥 REZZ - Web Vulnerability Scanner

## 🎯 Tujuan Tools Ini Dibuat

Tools ini dibuat untuk **developer, bug hunter, dan ethical hacker** agar bisa:
- Mengecek keamanan **website sendiri** sebelum diluncurkan
- Menemukan celah keamanan **sebelum dieksploitasi** hacker
- Belajar **web security** secara praktis dan real
